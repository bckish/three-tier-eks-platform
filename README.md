# Three-Tier Kubernetes Application

A hands-on Kubernetes project demonstrating the deployment and operation of a three-tier application consisting of a frontend, backend API, and database.

## Project Goals

- Deploy a three-tier application on Kubernetes
- Configure Kubernetes Deployments and Services
- Establish communication between application tiers
- Apply Kubernetes networking and configuration best practices
- Prepare the application for further production-grade improvements
